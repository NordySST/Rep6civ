# Rep6civ

Jogo 4X de estratégia por turnos **original** (civilizações, líderes, maravilhas e arte
inventados), em TypeScript + Canvas, jogável no navegador — inclusive por toque — e
instalável como PWA offline. Interface em português do Brasil.

- **Jogar:** https://nordysst.github.io/Rep6civ/
- Mapa hexagonal procedural com semente, névoa de guerra, rios, recursos e maravilhas naturais
- Cidades, cidadãos, produção, fronteiras, construtores e estradas
- Tecnologias, cívicas, governos e políticas, eurecas/inspirações
- Combate com terreno, ZOC, promoções, muralhas, bárbaros e navios
- Civilizações rivais com IA, diplomacia, agendas e cidades-estado
- Distritos com adjacência, maravilhas mundiais e habilidades únicas
- Economia, comodidades, rotas comerciais, religião e grandes personalidades
- Cinco caminhos de vitória: dominação, ciência, cultura, religião e pontuação

Desenvolvimento: `npm install && npm run dev` · Testes: `npm test` · Build: `npm run build`

Veja [CLAUDE.md](CLAUDE.md) para arquitetura, convenções, regras e o histórico das 8 etapas.
