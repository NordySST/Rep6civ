# Rep6civ

Jogo 4X de estratégia por turnos original, em TypeScript + Canvas, jogável no navegador
(também por toque) e instalável como PWA offline. Interface em português do Brasil.

- Jogar: https://nordysst.github.io/Rep6civ/
- Desenvolvimento: `npm install && npm run dev`
- Testes: `npm test` · Build: `npm run build`

Veja [CLAUDE.md](CLAUDE.md) para arquitetura, convenções e o plano das 8 etapas.
